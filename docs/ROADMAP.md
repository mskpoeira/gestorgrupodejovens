# Roadmap SGJ

## v0.3 — hardening local
- Cofre local criptografado.
- Backup criptografado.
- Correções de data local, grupos, radar, menoridade e taxa de presença.
- PWA segura, CSP do Tauri e testes automatizados.

## v0.4 — backend e identidade
- API central.
- Banco de dados transacional.
- Login, recuperação de conta e sessões revogáveis.
- RBAC por módulo e ação.
- Trilha de auditoria.

## v0.5 — sincronização Web/PC
- SQLite no Desktop.
- Fila offline local.
- Operações idempotentes.
- Resolução de conflitos.
- Sincronização incremental e observabilidade.

## v0.6 — módulos ampliados
- Inscrições e lista de espera.
- Escalas e voluntariado.
- Autorizações e documentos.
- Comunicação e notificações.
- Financeiro, patrimônio e relatórios gerenciais.

## Critério para dados reais de menores
O uso em produção com dados pessoais reais deverá ocorrer somente após autenticação central, autorização efetiva, auditoria, política de retenção, controles administrativos e revisão específica de privacidade/LGPD.
